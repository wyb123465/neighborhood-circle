# Design Brief

## Product purpose
邻里圈根据真实步行路网、设施分布和服务类别，帮助街道与社区识别15分钟生活圈的服务缺口并生成补短板建议。

## Primary user
街道或社区治理人员，在日常社区体检、老旧小区改造和公共服务布局中使用桌面端工作台。

## Principles
1. 先证明可达，再讨论数量：直线半径不能替代真实步行路线。
2. 结论必须落到行动：每一个缺口都应对应证据、优先级和下一步建议。
3. AI 负责组织，不负责编造：地图计算和统计结果确定，智能体负责理解需求、调工具和解释结果。
4. 一屏完成判断：用户进入页面后，应先看到结论，再按需查看原始点位和细节。
5. 能复现才算开源：没有 API Key 时也能用示例数据完整演示核心流程。

## Success metric for the surface
治理人员能在 60 秒内判断一个社区的主要服务缺口，并在 3 分钟内导出一份带证据的体检报告。演示者能用一次完整流程证明等时圈、设施统计和建议来自同一份可追溯数据。

## Out of scope
- 不替代正式城市规划审批和土地可行性论证。
- 不在第一阶段覆盖全市实时交通和人口预测。
- 不把自由聊天作为产品主体。
- 不将未经授权的真实居民隐私数据写入仓库。
