# 网页道路地图接入

网页端展示使用百度 JSAPI GL，点、网格和设施统一采用原始 BD-09 坐标。服务端仍使用 Web 服务 API 算路，两类 AK 分开配置。

## 配置

1. 百度开放平台控制台创建“浏览器端”应用，只启用 Javascript API 和 jsapi底图；本地演示使用 Referer `127.0.0.1,localhost`。控制台本次接受的是域名列表，不含协议、端口或路径。部署上线后改为实际站点域名。
2. 在本地 `.env` 填写空白模板中的 `BAIDU_BROWSER_AK`。原服务端 `BAIDU_MAP_AK` 和 IP 白名单继续用于后端请求。
3. 启动 assistant/live 模式，完成一次真实体检，选择“地理地图”；浏览器端 SDK 请求和底图请求需要可用网络。
4. 核对道路名称、中心位置、设施点、灰格、图层和缩放。错误信息若包含 Referer 或应用类型，应在控制台修正；不要改用服务端 AK 绕过校验。

`/api/map/display-config` 只返回专用浏览器 AK，并设置 no-store；如果两种配置相同则拒绝公开。浏览器 AK 本来会在网页请求中可见，保护方式为应用类型、服务权限和 Referer 限制，不承诺隐藏它。

无配置、SDK超时或网络错误时保留原测时示意与官方路线核对入口。默认 synthetic 离线启动不读取配置，也不加载 SDK。历史回放的测时来自录制时点；地理底图若启用仍是在线底图，不能声称整页完全离线。

## 网格表达

绿色深浅表示阈值内的测时层次，玫瑰色为阈值外，琥珀色为未知；虚线圈标识近阈值待复核。灰色网格对应1公里直线专项缺口；同一格尚有未知类别时使用琥珀色。

色块是以采样点为中心的邻域估计，不是全部区域实测可达，也不恢复河道或围墙的精确连通边界。粗格裁剪在本次采样范围内，加密格保留标记；不把采样点凸包包装成精确等时圈。原始测时、未知和证据编号保持独立。

官方依据：[JSAPI GL 使用须知](https://lbsyun.baidu.com/docs/jsapi?title=jspopularGL%2Fguide%2Fusage)、[覆盖物类参考](https://lbsyun.baidu.com/cms/jsapi/reference/jsapi_webgl_1_0.html)。
