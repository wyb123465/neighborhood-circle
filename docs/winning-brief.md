# 参赛定位与评分证据

更新于2026-10-14，当前版本0.7.0。

邻里圈面向社区调研，把服务缺口、原始测时、证据追问与候选复算连成同一流程。已实现的差异是受约束工具调用、未知保留、同样点情景复用和候选增益复算；尚未提供完整竞品实验，不宣称首创或行业领先。

## 命题对照

| 方向 | 现有证据 | 仍需补充 |
| --- | --- | --- |
| 功能正确性40% | 真实API、1公里专项、粗/细采样、坐标转换与证据编号 | 网页道路地图实际验收；固定社区独立路线/POI/缺口核验 |
| API工程30% | 矩阵拆批、加权限速、缓存、预算与失败未知；15次冷请求/0次热请求基准 | 更多网络与配额条件下的重复测量；多进程配额协调 |
| 产品体验15% | 统一工作台、设施联动、图层、情景、本机快照/备注和报告 | 非开发者实际试用和依据反馈的改进 |
| 开源规范15% | GitHub、MIT、独立源码、自动测试、格式与安全检查、贡献机制 | 维护责任持续执行，以实际贡献记录为准 |

官网通用标准另看技术创新30%、场景落地30%、开源治理20%、长期发展20%。不自行认定企业题替代官网标准；准备时同时覆盖，权重如何结合由组委会解释。

## 演示顺序

1. 无密钥合成案例：直线/绕行差异、养老缺口和候选独立增益。
2. 实际模型选择工具、读取证据、参数变化重算；保留真实轮次和请求数。
3. 配置完成后展示真实道路地图与测时网格、三类1公里专项及未知；配置不足时明确展示米制示意。
4. 情景复用、本机核验备注、报告与来源时点。
5. 展示真实对比中的三条分歧和未核验项，说明下一步验证方法。

当前没有可公开证明的用户访谈、政府合作、社区试点或收益数据。不编造用户原话、服务人数、节省成本、人口覆盖率或真实准确率。规划参考点不是建设选址。
