# 参赛收尾计划

> 本文记录 v0.4.1 的上一轮收尾范围。2026-10-13 新增的 [v0.5 完善计划](improvement-plan-v0.5.md) 将 AI 主线、设施统计与真实核验列为下一轮重点；这些新增能力目前尚未实现。

制定：2026-10-13。目标：准备可复现、口径一致、可供评委独立启动的作品与提交材料。

官网 https://www.oschina.net/os2026/ 于 2026-10-13 核验：报名及材料提交截止为 **2026-10-16 24:00（北京时间）**；入围名单 10 月 21 日，总决赛 10 月 29 日。旧文档的 10 月 11 日已过时。

| 顺序 | 工作 | 验收标准 |
| --- | --- | --- |
| P0 | 回放演示修复 | 无 AK 可回放；自动载入录制参数；页面、报告明确区分实时/回放；参数变化立即作废旧结果 |
| P0 | 专项缺口口径加固 | 检索覆盖样点周边 1 公里；分页截断、覆盖不足均保留未知；未知不参与候选增益 |
| P0 | 证据与测试 | 回归测试通过；生成合成真值对比及历史真实回放报告，分别注明来源与限制 |
| P0 | 独立复现 | Windows/Linux 启动脚本；独立源码包排除密钥、录制响应、虚拟环境和其他参赛项目 |
| P0 | 提交材料 | 项目介绍 PDF、演示脚本、材料填写模板、验收记录及源码包 |
| P1 | 人工独立核验 | 路线/POI 外部对照与来源可核对；无法完成的项明确留待复核，不写成已通过 |
| P1 | 公开与报名 | 团队确认署名、公开仓库及视频链接后自行报名、发布和发送材料 |

## 实施约束

- 保留现有绿色、系统字体和工作台布局；改动聚焦输入、状态、来源标识与证据。
- 赛题真实对比报告不能用合成测试或同一 API 的自检代替。
- 未提供团队名、作者和公开地址时保留明确的待填写项。
- 不自动报名、发送邮件或发布私人录制数据。

完成记录见 `docs/acceptance-2026-10-13.md` 与 `docs/delivery-checklist.md`。
