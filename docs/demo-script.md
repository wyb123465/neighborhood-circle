# 三分钟演示与解说

版本 v0.4.1。先启动 `start.ps1` 或 `bash start.sh`。历史回放演示另用 `start.ps1 -Mode replay`；其输入自动锁定为录制参数。实时演示用 `-Mode live`，先确认服务端 AK 权限与 IP 白名单。

| 时间 | 操作 | 解说要点 |
| --- | --- | --- |
| 0:00–0:20 | 首页，说明对象与问题 | 街道调研要判断服务缺口，直线范围不足以说明步行可达性。当前展示明确标注为合成样例。 |
| 0:20–0:55 | 点“演示预设”，定位路径 | 片区有河流和有限桥梁，直线圈内不一定能在 15 分钟到达。路径证据支持复算。 |
| 0:55–1:20 | 选第一个养老候选点，再撤销 | 在该合成样例、15 分钟和 80 米/分钟下，覆盖从 44.8% 到 92.3%，缺口 79 到 11；撤销回到原结果。分母是 143 个等权节点。 |
| 1:20–1:45 | 打开报告，查看证据编号与导出 | 数据来源、参数、候选模拟及未知边界一起保留。候选点不证明地块可建。 |
| 1:45–2:20 | 切到历史回放页，点“回放体检” | 显示 2026-10-13 录制的百度响应，本次不联网。样点可达比例不是人口覆盖率；粗网格与边界加密分开统计。 |
| 2:20–2:45 | 查看三类专项与分类提示 | 检索范围不足或分页未完整的点记为未知；培训机构命中“小学”不会被用于专项覆盖。 |
| 2:45–3:00 | 导出历史回放报告 | 报告注明模式和录制时间。20 条网页路线与三类 POI 的外部对照按单独记录交付，不用自动测试冒充。 |

## 录制要求

- 分辨率建议 1440×900 或 1920×1080，文字和关键指标应可读。
- 使用本地应用真实操作；等待过程可剪辑，切换到回放时保留模式说明。
- 不录入 `.env`、AK 或开发工具中的原始响应。
- 如使用截图讲解版视频，须注明“基于实际运行截图的分步演示”，不能称为连续屏幕实录。
- 若当前地图实时接口不可用，可演示合成 + 历史回放，明确两种来源。
