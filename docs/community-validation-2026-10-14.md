# 上海愚园路样区：真实对比验证汇总

日期：2026-10-14。版本：0.7.0。结论：真实接口与数据核对已具备，独立现实准确性仍待补证，不能写为“社区验证全部通过”。

## 固定样区与参数

- 样区：上海市长宁区愚园路片区；既有路线对照中心 BD-09 为纬度 31.225074、经度 121.435614。研究范围是计算包围盒/采样圆，不冒充社区行政边界。
- 社区居委名称、中心行政归属及实际可用入口尚未独立核实，提交前由团队补充，不能按道路名推断已选定的行政社区。
- 既有专项范围：中心周边1公里样点圆，250米间距，49个样点；缺口判断使用样点周边1公里直线距离。POI检索半径至少2公里，并检查分页完整性。
- 15分钟时间判断按百度原始秒数 ≤900；样点测时与设施统计不是居民人口覆盖率。画像 narrow 仅保留每类一个检索词，不等同于完整子类普查。

## 独立核验方案与待填记录

1. 确认一个可实地访问或取得可靠独立资料的社区/行政街道，写明样区名称、中心、时点和范围；保留既有愚园路样区作对照。
2. 选取阈值内、阈值外、近阈值和未知路线，特别保留现有三条分歧；说明抽样方法，不只挑容易验证的正例。
3. 分别核查菜市场、药店、小学，以及算法判定的缺口点：名称/资质、坐标来源、实际入口、营业/开放状态和可通行路径。
4. 独立参照可为带日期的现场计时、主管部门设施名录或其他可追溯资料。任务书没有强制必须现场计时，但同一百度平台的另一接口不能作为独立真值。
5. 逐行填入 `docs/templates/independent-checks.csv`，记录核验来源、日期、样本选择和分歧处理。未核验留空，不填“通过”。

## 当前不能给出的指标

尚无独立真值分母，不能报告现实路线准确率、盲区精确率/召回率或置信区间。现场/独立核验完成后，分别统计已核验、一致、不一致、未知，并公开聚合结果及限制；私人记录与原始响应保留本地。

## 工程基准复现

`python scripts/benchmark_live.py --allow-network` 在新进程中以每秒1个计量单元、单HTTP并发、单路线对拆批执行同输入冷/热对照，最多选择8处设施。报告只含聚合调用、耗时和证据编号，默认写入本地忽略目录。本脚本不进入CI，不把缓存提速称为批量算路提速。
