## 评委复现

Windows：`powershell -ExecutionPolicy Bypass -File .\start.ps1`。首次需要 Python 3.12/3.13 和网络安装依赖；启动后访问 http://127.0.0.1:8000 。

Linux/macOS：`bash start.sh`。Docker：`docker compose up --build`。默认合成模式不读取本地密钥、不请求地图。

AI演示：在本地填写模型配置后使用 `start.ps1 -Mode assistant -MapMode live`，访问 `/assistant.html`；没有百度AK时用 `-MapMode synthetic`。详见 `docs/ai-integration.md`。
